# 威胁检测

SSLcat 提供了威胁检测功能，可以识别和阻止恶意请求、机器人攻击和可疑行为。

## 功能概述

威胁检测功能通过分析请求特征、User-Agent、IP 地址等信息，自动识别威胁并采取相应的防护措施。

## 检测机制

### 1. User-Agent 检测

检测可疑的 User-Agent 模式：

- 恶意爬虫
- 扫描工具
- 自动化攻击工具

### 2. 威胁情报集成

集成威胁情报数据，识别已知恶意 IP：

- 已知恶意 IP 检测
- 恶意域名检测
- 恶意 URL 检测

### 3. 可疑行为检测

检测可疑的请求模式：

- 异常请求频率
- 异常请求路径
- 异常请求参数

## 配置说明

威胁检测功能是 WAF 和安全模块的一部分，通过以下配置启用：

```json
{
  "security": {
    "enable_waf": true,
    "enable_threat_intel": true
  }
}
```

## 使用场景

### 场景 1：机器人检测

检测和阻止恶意机器人：

```
请求 User-Agent: bad-bot/1.0
→ 威胁检测识别为恶意机器人
→ 阻止请求
→ 记录安全事件
```

### 场景 2：已知恶意 IP

检测已知恶意 IP：

```
请求来源 IP: 192.168.1.100 (已知恶意 IP)
→ 威胁情报识别为恶意 IP
→ 阻止请求
→ 记录安全事件
```
