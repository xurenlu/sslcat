# Web 管理界面

SSLcat 提供了现代、直观的基于 Web 的管理界面，用于配置、监控和管理代理服务器。

## 访问界面

### 默认访问
- **URL**: `http://localhost:8080/admin` (或您配置的管理端口)
- **默认用户名**: `admin`
- **默认密码**: `admin123` (请立即修改!)

### 自定义配置
```json
{
  "server": {
    "admin": {
      "enabled": true,
      "host": "0.0.0.0",
      "port": 8080,
      "path": "/admin",
      "auth": {
        "username": "admin",
        "password": "your-secure-password"
      }
    }
  }
}
```

主仪表板提供 SSLcat 实例的综合概览：

- **连接图**: 实时连接数变化

## 配置管理

### 代理规则管理
通过 Web 界面可以轻松管理代理规则：

#### 添加代理规则
1. 导航到 "代理规则" 页面
2. 点击 "添加规则" 按钮
3. 填写以下信息：
   - **域名**: 要代理的域名
   - **目标**: 后端服务器地址
   - **SSL**: 是否启用 SSL
   - **路径前缀**: 可选的路径前缀

#### 编辑代理规则
1. 在规则列表中找到要编辑的规则
2. 点击 "编辑" 按钮
3. 修改配置信息
4. 点击 "保存" 应用更改

#### 删除代理规则
1. 在规则列表中找到要删除的规则
2. 点击 "删除" 按钮
3. 确认删除操作

### SSL 证书管理

#### 证书状态
- **有效证书**: 显示所有有效证书
- **即将过期**: 30天内到期的证书
- **已过期**: 过期的证书
- **申请失败**: 申请失败的证书

#### 申请新证书
1. 导航到 "SSL 证书" 页面
2. 点击 "申请证书" 按钮
3. 填写域名和邮箱信息
4. 选择证书类型（Let's Encrypt 或自定义）
5. 点击 "申请" 开始申请过程

#### 证书续期
- **自动续期**: 系统自动续期即将过期的证书
- **手动续期**: 手动触发证书续期
- **批量续期**: 批量续期多个证书

## 用户管理

### 用户列表
- **用户名**: 用户登录名
- **角色**: 用户角色（管理员、操作员、查看者）
- **邮箱**: 用户邮箱地址
- **最后登录**: 最后登录时间
- **状态**: 用户状态（活跃、禁用）

### 创建用户
1. 导航到 "用户管理" 页面
2. 点击 "添加用户" 按钮
3. 填写用户信息：
   - **用户名**: 唯一用户名
   - **邮箱**: 用户邮箱
   - **密码**: 初始密码
   - **角色**: 选择用户角色
4. 点击 "创建" 完成用户创建

### 权限管理
- **管理员**: 完全访问所有功能
- **操作员**: 监控和基本配置权限
- **查看者**: 只读访问权限
