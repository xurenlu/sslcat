# 系统要求

本指南介绍运行 SSLcat 所需的系统要求，包括硬件、软件和网络要求。

## 硬件要求

### 最低要求
- **CPU**: 1 核心
- **内存**: 512MB RAM
- **存储**: 1GB 可用空间
- **网络**: 100Mbps 网络连接

### 推荐配置
- **CPU**: 2+ 核心
- **内存**: 2GB+ RAM
- **存储**: 10GB+ 可用空间
- **网络**: 1Gbps 网络连接

### 生产环境
- **CPU**: 4+ 核心
- **内存**: 4GB+ RAM
- **存储**: 50GB+ 可用空间
- **网络**: 10Gbps 网络连接

## 操作系统要求

### 支持的操作系统
- **Linux**: Ubuntu 18.04+, CentOS 7+, RHEL 7+, Debian 9+
- **macOS**: 10.14+ (Mojave+)
- **Windows**: Windows 10+, Windows Server 2016+

### 推荐操作系统
- **Linux**: Ubuntu 20.04 LTS, CentOS 8, RHEL 8
- **macOS**: macOS 11+ (Big Sur+)
- **Windows**: Windows Server 2019+

## 软件依赖

### 必需软件
- **Go**: 1.21+ (用于从源码构建)
- **Docker**: 20.10+ (用于容器部署)
- **OpenSSL**: 1.1.1+ (用于 SSL/TLS 支持)

### 可选软件
- **Redis**: 6.0+ (用于缓存)
- **Prometheus**: 2.30+ (用于监控)
- **Grafana**: 8.0+ (用于可视化)
- **Jaeger**: 1.30+ (用于分布式追踪)

## 网络要求

### 端口要求
- **HTTP**: 80 (必需)
- **HTTPS**: 443 (必需)
- **管理界面**: 8080 (可选)
- **监控**: 9090 (可选)

### 防火墙配置
```bash
# 开放必需端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 8080/tcp  # 管理界面
sudo ufw allow 9090/tcp  # 监控
```

### DNS 要求
- **域名解析**: 确保域名正确解析到服务器
- **DNS 记录**: 配置 A 记录或 CNAME 记录
- **子域名**: 支持子域名配置

## 安全要求

### SSL/TLS 证书
- **Let's Encrypt**: 自动证书管理
- **自定义证书**: 支持 PEM 格式证书
- **证书链**: 支持中间证书链

### 访问控制
- **IP 白名单**: 限制管理界面访问
- **用户认证**: 支持基本认证和 JWT
- **角色权限**: 支持基于角色的访问控制

## 性能要求

### 并发连接
- **最低**: 100 并发连接
- **推荐**: 1000+ 并发连接
- **生产**: 10000+ 并发连接

### 吞吐量
- **最低**: 100 请求/秒
- **推荐**: 1000+ 请求/秒
- **生产**: 10000+ 请求/秒

### 延迟要求
- **响应时间**: < 100ms (P95)
- **SSL 握手**: < 50ms
- **缓存命中**: < 10ms

## 存储要求

### 数据存储
- **配置数据**: 10MB
- **日志文件**: 1GB/月
- **证书存储**: 100MB
- **缓存数据**: 根据配置

### 备份要求
- **配置备份**: 每日备份
- **证书备份**: 每周备份
- **日志归档**: 每月归档

## 监控要求

### 系统监控
- **CPU 使用率**: < 80%
- **内存使用率**: < 80%
- **磁盘使用率**: < 80%
- **网络使用率**: < 80%

### 应用监控
- **请求成功率**: > 99%
- **响应时间**: < 100ms
- **错误率**: < 0.1%
- **可用性**: > 99.9%

- **网络**: 100Mbps

## 云平台要求

### AWS
- **实例类型**: t3.medium+ (生产环境)
- **存储**: EBS GP3 20GB+
- **网络**: VPC 配置
- **安全组**: 开放必需端口

### Azure
- **虚拟机**: Standard_B2s+ (生产环境)
- **存储**: 托管磁盘 20GB+
- **网络**: 虚拟网络配置
- **网络安全组**: 开放必需端口

### Google Cloud
- **实例类型**: e2-medium+ (生产环境)
- **存储**: 持久化磁盘 20GB+
- **网络**: VPC 配置
- **防火墙规则**: 开放必需端口

## 故障排除

### 常见问题
1. **端口被占用**: 检查端口使用情况
2. **权限不足**: 检查文件权限
3. **网络不通**: 检查防火墙和网络配置
4. **DNS 解析失败**: 检查 DNS 配置
5. **证书问题**: 检查证书配置和有效性

### 诊断命令
```bash
# 检查端口使用
netstat -tlnp | grep :80
netstat -tlnp | grep :443

# 检查进程
ps aux | grep sslcat

# 检查日志
tail -f /var/log/sslcat/sslcat.log

# 检查配置
sslcat -config sslcat.conf -validate
```
