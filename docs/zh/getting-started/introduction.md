# SSLcat 介绍

## 什么是 SSLcat？

SSLcat 是一个企业级 SSL 代理服务器，专为现代 Web 应用程序和微服务架构设计。它提供自动 SSL 证书管理、智能域名转发、负载均衡、缓存和现代 Web 管理界面。

## 核心功能

### 🔒 SSL/TLS 终端
- **自动证书管理**: Let's Encrypt 集成，自动续期
- **多域名支持**: 单个实例处理多个域名
- **SSL/TLS 优化**: 现代密码套件和安全最佳实践
- **证书监控**: 实时证书状态和过期提醒

### 🌐 反向代理
- **智能路由**: 基于域名的智能请求转发
- **协议支持**: HTTP/1.1、HTTP/2 和 WebSocket 支持
- **头部管理**: 自动代理头部和自定义头部注入
- **请求/响应修改**: 灵活的请求和响应处理

### ⚖️ 负载均衡
- **多种算法**: 轮询、最少连接、IP 哈希和加权
- **健康检查**: 自动后端健康监控
- **故障转移**: 自动故障转移到健康后端
- **会话持久化**: 有状态应用程序的粘性会话

### 🚀 性能特性
- **智能缓存**: 多层缓存系统，支持 CDN
- **压缩**: Gzip/Brotli 压缩，智能缓存
- **HTTP/2 支持**: 完整的 HTTP/2 服务器和客户端支持
- **连接池**: 优化的连接管理

### 📊 监控与可观测性
- **分布式追踪**: 完整支持 OpenTelemetry、Jaeger 和 Zipkin
- **指标**: Prometheus 兼容指标
- **日志**: 结构化日志，多种输出
- **实时监控**: 基于 Web 的监控仪表板

### 🛡️ 安全
- **DDoS 防护**: 内置 DDoS 防护和速率限制
- **访问控制**: 用户认证和授权
- **安全头部**: 自动安全头部注入
- **IP 过滤**: 白名单/黑名单 IP 管理

## 使用场景

### 1. **微服务网关**
- 将流量路由到多个后端服务
- 处理所有服务的 SSL 终端
- 提供统一的认证和授权
- 实现服务发现和负载均衡

### 2. **遗留应用现代化**
- 为遗留 HTTP 应用添加 SSL/TLS
- 实施现代安全实践
- 添加缓存和压缩
- 启用 HTTP/2 支持

### 3. **开发环境**
- 本地 SSL 开发，自动证书
- 复杂应用的多域名支持
- 简单的后端切换和测试
- 开发友好的配置

### 4. **生产负载均衡器**
- 高性能负载均衡
- 健康监控和故障转移
- SSL 终端和优化
- 监控和告警

┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   客户端        │    │   SSLcat        │    │   后端服务      │
│   (浏览器)      │◄──►│   代理          │◄──►│   服务          │

                              │
                              ▼

                       └─────────────────┘

### 核心组件

1. **SSL 终端层**: 处理 SSL/TLS 加密/解密
2. **代理引擎**: 将请求路由到后端服务
3. **负载均衡器**: 在多个后端之间分发流量
4. **缓存管理器**: 管理内容缓存和压缩
5. **监控系统**: 收集指标和追踪
6. **管理界面**: 基于 Web 的管理
