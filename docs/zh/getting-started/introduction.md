# SSLcat 介绍

SSLcat 是一个功能强大的高性能 SSL 代理服务器，旨在简化 SSL 证书管理并提供智能域名转发功能。使用 Go 语言构建，SSLcat 提供企业级功能，并具有用户友好的 Web 界面。

## 🌟 核心功能

### 🔒 自动 SSL 证书管理
- **Let's Encrypt 集成**：自动获取和续期 SSL 证书
- **多域名支持**：通过单一配置处理多个域名
- **证书缓存**：优化的证书存储和检索
- **测试环境**：使用 Let's Encrypt 测试证书进行安全测试

### 🔄 智能域名转发
- **智能代理路由**：基于域名的智能代理转发
- **HTTP/HTTPS 支持**：完整的协议支持，自动 SSL 终止
- **WebSocket 代理**：实时通信支持
- **负载均衡**：多后端服务器支持，带健康检查

### 🛡️ 高级安全功能
- **IP 阻止**：可配置阈值的自动 IP 阻止
- **暴力破解保护**：针对暴力破解攻击的高级保护
- **User-Agent 验证**：基于用户代理的请求过滤
- **TLS 客户端指纹识别**：基于 TLS 特征的客户端识别
- **访问日志**：全面的访问和安全日志记录

### 🎛️ Web 管理界面
- **直观仪表板**：实时系统监控和统计
- **证书管理**：可视化证书状态和管理
- **代理规则配置**：易于使用的代理规则设置
- **安全监控**：实时安全事件监控
- **API 令牌管理**：细粒度的 API 访问控制

### ⚡ 高性能
- **HTTP/2 支持**：现代协议支持，自动协商
- **HTTP/3 (QUIC) 支持**：下一代协议支持
- **连接池**：优化的连接管理
- **优雅重启**：零停机时间服务更新
- **资源优化**：高效的内存和 CPU 使用

## 📊 性能特征

SSLcat 专为高性能和可扩展性设计：

- **并发连接**：支持数千个并发连接
- **证书缓存**：优化的证书存储和检索
- **内存效率**：低内存占用，高效资源使用
- **CPU 优化**：多核支持，优化处理
- **网络性能**：高吞吐量代理，最小延迟

## 🔧 系统要求

### 最低要求
- **CPU**：1 核心，1 GHz
- **内存**：512 MB RAM
- **存储**：1 GB 可用空间
- **网络**：100 Mbps 连接
- **操作系统**：Linux (Ubuntu 18.04+, CentOS 7+), macOS 10.14+, Windows 10+

### 推荐要求
- **CPU**：2+ 核心，2+ GHz
- **内存**：2+ GB RAM
- **存储**：10+ GB 可用空间
- **网络**：1+ Gbps 连接
- **操作系统**：Linux (Ubuntu 20.04+, CentOS 8+), macOS 11+, Windows 11+

## 📈 监控和可观测性

SSLcat 提供全面的监控功能：

- **实时指标**：连接数、请求率、错误率
- **证书状态**：证书过期监控
- **安全事件**：登录失败、被阻止的 IP
- **性能指标**：响应时间、吞吐量、资源使用
- **健康检查**：服务可用性和后端健康

## 🔒 安全考虑

SSLcat 实现多层安全：

- **传输安全**：TLS 1.2+ 与现代密码套件
- **访问控制**：基于角色的访问控制 (RBAC)
- **审计日志**：全面的安全事件日志
- **输入验证**：严格的输入验证和清理
- **速率限制**：防止滥用和 DoS 攻击
