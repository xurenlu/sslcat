# Git 部署服务 Web UI 功能总结

## 概述

为 Git SSH 部署功能添加了完整的 Web UI 界面，方便用户通过图形化界面管理应用、查看推送记录和配置SSH密钥权限。

## 新增组件

### 1. PushHistory - 推送历史记录组件

**位置**: `frontend/src/components/PushHistory.tsx`

**功能特性**:
- 📊 显示应用的所有Git推送历史记录
- 🔍 查看每次推送的详细信息
- ⏱️ 显示推送耗时和大小
- 📝 显示提交哈希和提交消息
- 👤 显示推送者信息（SSH密钥、IP地址）
- 🎯 支持状态筛选（成功/失败/进行中）

**数据展示**:
```typescript
interface PushRecord {
  id: string                // 推送ID
  app_name: string          // 应用名称
  pusher_key: string        // SSH密钥指纹
  pusher_name: string       // 推送者名称
  commit_hash: string       // 提交哈希
  commit_message: string    // 提交消息
  ref_name: string          // 分支/标签名
  status: string            // pending/success/failed
  start_time: string        // 开始时间
  end_time: string          // 结束时间
  duration: number          // 耗时（毫秒）
  error_message: string     // 错误信息
  log_file: string          // 日志文件路径
  push_size: number         // 推送大小（字节）
  client_ip: string         // 客户端IP
}
```

**UI 截图功能**:
- 表格列：时间、提交、分支、状态、耗时、推送者、操作
- 状态徽章：
  - 🟢 成功 - 绿色徽章
  - 🔴 失败 - 红色徽章
  - 🟡 进行中 - 黄色徽章

### 2. SSHKeyBindings - SSH密钥绑定管理组件

**位置**: `frontend/src/components/SSHKeyBindings.tsx`

**功能特性**:
- 🔐 管理应用的SSH密钥访问权限
- ➕ 绑定SSH密钥到指定应用
- ➖ 解绑SSH密钥
- 📋 显示所有可用的SSH密钥
- 🔓 权限模式切换（开放/限制）
- ⚠️ 权限状态可视化提示

**权限模型**:
1. **开放模式**（默认）
   - 所有已添加的SSH密钥都可以推送
   - 适合小团队或个人使用
   
2. **限制模式**
   - 只有绑定的SSH密钥可以推送
   - 适合多人协作，需要精细化权限控制

**UI 功能**:
- 显示已绑定的密钥列表
- 显示未绑定的密钥数量提示
- 一键绑定/解绑操作
- 权限状态警告提示

## 使用流程

### 1. 查看推送历史

```
1. 进入 Git 服务器管理页面
2. 选择一个应用
3. 点击「推送记录」标签
4. 查看推送历史表格
5. 点击「详情」按钮查看完整信息
```

### 2. 管理SSH密钥绑定

```
1. 进入「推送记录」标签
2. 滚动到「SSH密钥绑定」区域
3. 点击「绑定密钥」按钮
4. 选择要绑定的SSH密钥
5. 确认绑定
```

### 3. 解绑SSH密钥

```
1. 在已绑定密钥列表中
2. 点击密钥右侧的删除图标
3. 确认解绑操作
```

## API 接口对接

### 推送历史 API

```typescript
// 获取推送历史
GET /api/git-server/push-history?app={appName}&limit={limit}

Response:
{
  "success": true,
  "data": [
    {
      "id": "push_1704067200",
      "app_name": "myapp",
      "pusher_key": "SHA256:xxxxx",
      "commit_hash": "abc123",
      "status": "success",
      ...
    }
  ],
  "count": 50
}
```

### SSH密钥绑定 API

```typescript
// 绑定密钥
POST /api/git-server/app/bind-key
{
  "app_name": "myapp",
  "key_fingerprint": "SHA256:xxxxx"
}

// 解绑密钥
POST /api/git-server/app/unbind-key
{
  "app_name": "myapp",
  "key_fingerprint": "SHA256:xxxxx"
}

// 获取所有SSH密钥
GET /api/git-server/ssh-keys
```
