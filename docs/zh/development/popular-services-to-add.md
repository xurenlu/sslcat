# 当前流行的服务推荐清单

基于当前模板库（237个），以下是当前比较流行但可能尚未添加的服务：

## 一、Notion 替代品和笔记工具

### 高优先级
1. **Obsidian** - 强大的知识管理工具，支持 Markdown 和插件系统
2. **Logseq** - 大纲式笔记工具，支持双向链接
3. **AppFlowy** - Notion 的开源替代品，Rust + Flutter
4. **TiddlyWiki** - 非线性个人知识库
5. **RemNote** - 知识管理和学习工具

## 二、协作和通信工具

### 高优先级
1. **Mattermost** - Slack 的开源替代品（社区版已有，可添加企业版）
2. **Rocket.Chat** - 实时聊天平台（已有，可确认）
3. **Element (Matrix)** - 去中心化聊天，Matrix 协议
4. **Zulip** - 话题流式团队聊天（已有，可确认）
5. **Mumble** - 低延迟语音聊天
6. **Jitsi Meet** - 开源视频会议

## 总结

当前模板库已经有 **237 个模板**，覆盖了大部分主流应用场景。建议优先添加：

1. **工作流自动化**（N8N, Huginn）
2. **Notion 替代品**（Obsidian, Logseq, AppFlowy）
3. **API 网关**（Kong, Traefik）
4. **任务调度**（Airflow, Prefect）
5. **VPN**（WireGuard）
6. **广告拦截**（Pi-hole）
7. **游戏服务器**（Minecraft）

这些服务在当前市场上非常流行，添加后可以进一步提升产品的竞争力。
