# Terminal UI 使用文档

## 概述

SSLcat Terminal UI 是一个基于 Bubbletea 的交互式终端控制台，提供了完整的代理规则配置管理功能。通过直观的多步骤配置向导，您可以轻松管理复杂的代理规则配置。

## 快速开始

### 启动控制台

```bash
sslcat -config /path/to/config.json console
```

或使用别名：

```bash
sslcat -config /path/to/config.json interactive
```

### 基本操作

- **方向键 (↑↓)** 或 **j/k**: 在列表中上下移动
- **Enter**: 选择/确认
- **q** 或 **Esc**: 退出/返回
- **Tab**: 在表单字段间切换
- **Shift+Tab**: 反向切换字段

## 代理规则管理

### 基础操作

在代理规则管理页面：

- **a**: 添加新规则（打开高级配置向导）
- **A**: 添加新规则（简单模式）
- **e**: 编辑规则（打开高级配置向导）
- **d**: 删除规则
- **s**: 保存配置到文件
- **q/Esc**: 返回主菜单

### 高级配置向导

代理规则高级配置包含 9 个步骤，使用左右箭头键（←→）或 **h/l** 键切换：

#### 步骤 1: 基础配置
- 域名 (domain)
- 启用状态 (enabled)
- SSL Only (ssl_only)

#### 步骤 2: 后端服务器
- **a**: 添加后端服务器
- **e**: 编辑选中的后端
- **d**: 删除选中的后端

后端服务器配置项：
- 主机地址 (host)
- 端口 (port)
- 权重 (weight)
- 优先级 (priority)
- 启用状态 (enabled)

#### 步骤 3: 负载均衡
- 负载均衡算法选择
  - round_robin: 轮询
  - weighted_round_robin: 加权轮询
  - least_conn: 最少连接
  - ip_hash: IP 哈希
  - random: 随机
  - consistent_hash: 一致性哈希

#### 步骤 4: 健康检查
- 启用状态
- 检查路径
- 检查间隔（秒）
- 超时时间（秒）
- HTTP 方法
- 期望状态码

#### 步骤 5: 会话保持
- 启用状态
- 方法 (cookie/header/ip)
- Cookie 名称
- TTL（秒）

#### 步骤 6: 故障转移
- 启用状态
- 最大重试次数
- 重试间隔（秒）
- 故障阈值
- 恢复阈值

#### 步骤 7: 高级选项
- HTTP Host 头部优化
- CDN 启用
- CDN 预设
- CDN TTL（秒）
- WebSocket 优化开关

#### 步骤 8: 路径前缀规则
- **a**: 添加路径前缀规则
- **e**: 编辑选中的规则
- **d**: 删除选中的规则

路径前缀规则配置：
- 规则名称
- 规则描述
- 路径前缀（逗号分隔）
- 精确匹配开关
- 启用状态

#### 步骤 9: 自定义头部
- **t**: 切换请求头/响应头类型
- **a**: 添加头部
- **e**: 编辑选中的头部
- **d**: 删除选中的头部

### 保存配置

在高级配置向导中，按 **s** 键保存配置并退出。配置会自动保存到指定的配置文件。

## 配置管理

### 浏览配置

在主菜单选择"配置管理"，可以浏览所有配置项：

- **↑↓/jk**: 移动选择
- **Enter**: 编辑选中的配置项
- **/** 或 **f**: 搜索配置
- **q**: 返回

### 编辑配置

选择配置项后，可以：
- 直接输入新值
- **Enter**: 保存
- **Esc**: 取消

## 状态监控

查看系统状态信息：
- Go 版本
- 操作系统信息
- 配置文件路径
- 代理规则数量
- SSL 证书数量

## 文件结构

Terminal UI 代码组织：

```
internal/cli/ui/
├── common.go                    # 通用样式和工具函数
├── menu.go                      # 主菜单
├── config_view.go              # 配置管理视图
├── status_view.go              # 状态监控视图
├── proxy_view.go               # 代理规则列表视图
├── proxy_advanced_view.go      # 代理规则高级配置主视图
├── proxy_backend_manager.go     # 后端服务器管理模块
├── proxy_path_prefix_manager.go # 路径前缀规则管理模块
└── proxy_headers_manager.go    # 自定义头部管理模块
```

## 开发指南

### 添加新功能模块

1. 在 `internal/cli/ui/` 目录下创建新的管理器文件
2. 实现 `Update` 和 `View` 方法
3. 在主视图中集成管理器

### 代码规范

- 单个文件不超过 3000 行
- 使用模块化设计，功能独立管理
- 保持代码结构清晰，易于维护

## 故障排除

### 控制台无法启动

1. 检查配置文件路径是否正确
2. 检查配置文件格式是否正确
3. 检查是否有足够的权限

### 配置保存失败

1. 检查配置文件是否有写权限
2. 检查配置文件格式是否正确
3. 查看错误消息获取详细信息

### 快捷键不响应

确保终端支持 ANSI 转义序列。某些终端可能需要特殊配置。
