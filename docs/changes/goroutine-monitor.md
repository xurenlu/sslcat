# Goroutine 监控误报与手动基线重置

发布单元：SSLcat。类型：Fixed / Added。此片段不分配发布版本。

- 启动后先预热 5 分钟，以采样中位数确定基线。
- 警告同时要求超过基线 100 个及连续 3 次上升趋势；超过基线 500 个的严重告警仍保留。
- 告警冷却 10 分钟，冷却中仍计数，避免重复日志和堆栈输出。
- 增加需要写权限的 `POST <admin_prefix>/api/monitoring/baselines/reset`，统一校准现有监控基线。
- 修复统计读取中的递归读锁风险，覆盖稳态采样、持续增长、冷却、重置与并发访问。

兼容影响：预热期间不告警；趋势判定需要至少 20 次采样。重置操作应在确认业务稳定后执行。
