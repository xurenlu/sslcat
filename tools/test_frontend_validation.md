# 前端用户管理验证测试

## 🎯 测试目标
验证前端用户管理页面的输入验证功能是否正常工作。

## 🔧 添加的验证规则

### 1. **用户名验证**
- ✅ 长度至少 3 个字符
- ✅ 不能为空
- ✅ 去除前后空格

### 2. **密码验证**
- ✅ 长度至少 6 个字符
- ✅ 不能为空（添加用户时）
- ✅ 密码确认匹配

### 3. **角色验证**
- ✅ 必须选择角色
- ✅ 不能为空

## 📝 测试步骤

### 测试 1: 用户名太短
1. 打开用户管理页面
2. 点击"添加用户"
3. 输入用户名: `ab` (少于3个字符)
4. 输入密码: `123456`
5. 选择角色: `viewer`
6. 点击"创建用户"
7. **预期结果**: 显示错误提示 "用户名长度至少3个字符"

### 测试 2: 密码太短
1. 输入用户名: `testuser`
2. 输入密码: `123` (少于6个字符)
3. 选择角色: `viewer`
4. 点击"创建用户"
5. **预期结果**: 显示错误提示 "密码长度至少6个字符"

### 测试 3: 密码确认不匹配
1. 输入用户名: `testuser`
2. 输入密码: `123456`
3. 确认密码: `654321` (不匹配)
4. 选择角色: `viewer`
5. 点击"创建用户"
6. **预期结果**: 显示错误提示 "密码确认不匹配"

### 测试 4: 未选择角色
1. 输入用户名: `testuser`
2. 输入密码: `123456`
3. 确认密码: `123456`
4. 不选择角色
5. 点击"创建用户"
6. **预期结果**: 显示错误提示 "请选择用户角色"

### 测试 5: 编辑用户密码太短
1. 选择一个现有用户，点击"编辑"
2. 输入新密码: `123` (少于6个字符)
3. 点击"保存更改"
4. **预期结果**: 显示错误提示 "密码长度至少6个字符"
