# WireGuard (VPN 服务) 模板

现代化的 VPN 解决方案，性能优异，配置简单，适合企业内网远程访问和站点间连接。

## 功能特性

- ✅ Web 应用服务
- ✅ 健康检查支持
- ✅ 数据持久化存储
- ✅ 多服务架构

## 默认凭证

部署后，系统会自动生成以下凭证：

- **wireguard 密码**: 自动生成（16位随机密码）

## 首次访问

1. 访问 `http://{{PRIMARY_DOMAIN}}`
2. 按照安装向导完成配置
3. 使用系统生成的凭证登录

## 数据持久化

所有数据存储在 Docker volumes 中：

- `wireguard_config`: wireguard-webui 配置文件
- `wireguard_config`: wireguard 配置文件
- `wireguard_modules`: wireguard 数据存储

**重要**: 即使容器重启，所有数据都会保留。

## 管理命令

```bash

# 停止服务
docker-compose -f docker-compose.yml -p sslcat-{app_name} stop

# 启动服务
```
