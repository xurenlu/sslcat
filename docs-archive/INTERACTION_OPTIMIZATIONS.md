## 🎨 Toast 提示标准化

### 消息类型和用法

#### ✅ **成功消息** (status: 'success')
```typescript
toast({
  title: '操作成功',
  description: '具体的成功描述',
  status: 'success',
  duration: 3000,
  isClosable: true,
})
```

#### ⚠️ **警告消息** (status: 'warning')
```typescript
toast({
  title: '表单验证失败',
  description: '请检查输入的内容',
  status: 'warning',
  duration: 3000,
  isClosable: true,
})
```

#### ❌ **错误消息** (status: 'error')
```typescript
toast({
  title: '操作失败',
  description: error instanceof Error ? error.message : '未知错误',
  status: 'error',
  duration: 4000,  // 错误消息显示更长时间
  isClosable: true,
})
```

#### ℹ️ **信息消息** (status: 'info')
```typescript
toast({
  title: '操作已启动',
  description: '正在处理您的请求',
  status: 'info',
  duration: 2000,
  isClosable: true,
})
```

### 持续时间标准
- **成功消息**: 3000ms (3秒)
- **信息消息**: 2000ms (2秒)
- **警告消息**: 3000ms (3秒)
- **错误消息**: 4000ms (4秒)
